# Supported sources

Generated from `spec/ingest/support-matrix.yaml`, so this page and the matrix never disagree. **46 of 54 sources are supported**: AgentCE reads each one exactly as its published definition says — the producer's code first, then its machine-readable schema, then its prose. **4 are experimental**, where the producer calls the interface a preview or beta, or a field AgentCE reads is defined nowhere. **4 are on the roadmap**, where we'd welcome help.

## Roadmap (4)

No published definition yet, or nothing safe to read. We'd welcome help.

| Source | Format | Why it's not supported yet | Help wanted |
|---|---|---|---|
| Cursor | closed SQLite and transcript stores | Closed stores that only real output can define | Help wanted: a census of real stores |
| LangGraph dev server checkpoints | Python pickle files | Opening a pickle can run code | Help wanted: a safe export from the dev server; meanwhile read the agent's traces |
| OpenAI Agents SDK hosted traces | traces the SDK uploads to OpenAI | OpenAI documents no way to read them back | Help wanted: an export path; meanwhile write spans to a file with a TracingProcessor or an OpenInference instrumentation |
| Cedar | a library; the host decides what to log | Cedar writes no log; only its host can | Help wanted: a host logging convention, or readers for cedar-local-agent and Verified Permissions |
