AgentCE OSCAL Assessment Results (profile).

The subset of NIST OSCAL Assessment Results that AgentCE emits as oscal-ar.json (SPEC 9), so a governance platform can consume outcomes in a format it already reads. This is a bounded profile validated in Phase 1; full OSCAL conformance is completed with the standards-alignment work (item 5.5).
