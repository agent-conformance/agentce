AgentCE OSCAL Component Definition (profile).

The subset of NIST OSCAL Component Definition that AgentCE publishes as oscal-component-definition.json (SPEC 2.1, 7.3): AgentCE described as a validation component whose control implementation targets the EU AI Act base catalog, one implemented requirement per control. This is a bounded profile authored with the standards-alignment work (item 5.5); it is generated from the catalog and validated by validate_oscal.py.
