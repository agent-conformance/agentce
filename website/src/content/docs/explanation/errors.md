Every message the engine surfaces carries a stable key. This catalogue is generated by `agentce doctor --write-errors`; do not edit it by hand (SPEC §13.4).

## Errors

| Key | Cause | Fix |
|---|---|---|
| `catalog.control.min_source_class_unknown` | control {control} declares min_source_class {value}, which is not a source class: the value must be exactly self_report, enforcement_point or independent_system (SPEC §6.4), so the engine could not tell which records the control accepts. | set evaluation.min_source_class to self_report, enforcement_point or independent_system, written in lowercase as here; any is not a source class, and self_report is the lowest minimum a control can declare. |
| `catalog.control.requires_denominator_invalid` | control {control} declares requires_denominator {value}, which is not an object with exactly two keys: kinds, a non-empty list without repeats drawn from provider_usage_export, egress_proxy_log, firewall_log, system_of_record_export and admission_attestation, and covers, an event type name (SPEC §6.5). The engine could not tell which declared count a verdict needs. | set evaluation.requires_denominator to {kinds: [...], covers: <EventType>} with each kind spelled as listed, or remove it if the verdict needs no declared denominator. |
| `catalog.control.source_class_from_unknown` | control {control} declares source_class_from {value}, which is not a list of graph links: each entry must be exactly actsOn, approvedBy, delegatedVia or releasedBy (SPEC §7.1), so the engine could not tell which records the judgment rests on. | set evaluation.source_class_from to a list of actsOn, approvedBy, delegatedVia or releasedBy, written as here, or remove it when the judgment rests on the focus record alone. |
| `catalog.evidence_shape.passed_case_unjudged` | control {control}'s test case {case} expects passed, but its evidence shape targets nothing in that fixture or finds a record it cannot judge, so assess would never read it conformant. | check the evidence shape's target (a misspelt class targets nothing) and give the passed fixture the records the evidence shape asks for. |

## Quarantine reasons

| Key | Cause | Fix |
|---|---|---|
| `class_mismatch` | the event's source class differs from the class declared for its source. | ask whoever wrote the source adapter to align the emitted agentceSourceClass with the profile's declared class. |
| `context_mismatch` | the event's JSON-LD @context is not the canonical evidence context. | ask whoever wrote the source adapter to set @context to https://agent-conformance.org/contexts/evidence/v1. |
| `duplicate_id` | two events share the same id; the one from the lower trust class was quarantined, or the later one if both have the same class. | ask whoever instruments the source to give every event a stable, unique id. |
| `oversize` | the event exceeds the size limit and was refused. | ask whoever wrote the source adapter to reference bulk content by an opaque locator instead of inlining it (SPEC R12). |
| `schema_invalid` | an event failed schema validation and was not ingested. | ask whoever wrote the emitter or adapter to fix it so the event matches agentce-evidence.schema.json. |
| `time_order` | an event's timestamp is out of order within its stream. | ask whoever instruments the source to emit events in time order, or correct the source clock. |
| `unknown_source` | the event's source is not declared in the applicability profile. | declare the source under the subject's evidence_sources with its trust class. |
| `unknown_type` | the event's @type is not a recognised evidence type. | ask whoever wrote the adapter to map the event to a canonical evidence type (SPEC §12). |
