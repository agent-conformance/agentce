Every tab below shows the command for one way to run the engine. A zero-install command appears in its
tab only once the package is published on that channel; until then the tab says so and shows the command
that works from a checkout of the repository today.

<InstallTabs />

The first run needs no account, no network access after the install, and no model. See
[Getting Started](/docs/getting-started/) for what the quickstart prints and the prerequisites for each
platform.
