# Quickstart project

A small, complete credit-decisioning project an adopter can assess before instrumenting anything.
It is the input to `agentce quickstart`, which runs a full assessment over it and writes a report.

```
uv run --project engines/python agentce quickstart --out ./out
```

The bundle records one consequential credit decision with enforcement-point evidence — a verified
delegation ending at a human overseer, the gateway-recorded tool call, and an incident register entry.
It is small on purpose: a run over it shows what the evidence settles and where it does not.

A run over this project ends with 25 conformant, 19 insufficient evidence, 5 not assessed, of 49 controls.

- **Insufficient evidence** means the control applies and was evaluated, but the evidence collected did not meet its minimum evidence or source class. It is a gap in what was collected, not a failure and not a guess: the engine reports conformant only when the evidence supports it.
- **Not assessed** means the control applies but was not evaluated, for example because a manual checklist is absent or a metric is below its minimum population.
