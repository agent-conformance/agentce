# agentce (alias)

This package contains no code of its own. It depends on `@agent-conformance/cli`, which provides the
`agentce` command: the Node implementation of the Agent Conformance Engine. Either name gives the same
engine at the same version. That engine implements the conformance-suite run and `--version` today; the
assessment commands are documented as roadmap. See https://github.com/agent-conformance/agentce.
